# Proposal: ScreenPal Android 屏幕识别 + 语音播报 App

## Summary

创建一个 Android 应用，用户点击桌面悬浮球即可在当前屏幕任意应用界面框选区域，应用自动对选中区域进行 OCR 文字识别，并用 Piper 神经语音（端侧优先，云端可选增强）播报识别结果。

## Motivation

- 当前 Android 上缺乏"跨应用、轻量、离线可用"的屏幕文字识别 + 语音播报工具
- 用户需要在任何应用（浏览器、聊天、阅读器）中快速提取文字并听取内容
- 传统截图工具只提供截取和保存，不提供 OCR 和 TTS 集成
- 悬浮球 + 框选模式是最高效的交互方式：无需切换 App，一键触发

## Goals

1. 退出 App 后桌面显示悬浮球，任何应用界面都可点击触发识别
2. 全屏透明框选界面，手指拖拽绘制矩形选区，松开确认
3. MediaProjection 截取当前屏幕，裁剪选中区域
4. ML Kit 端侧 OCR 识别文字，置信度低于阈值时自动调用云端增强
5. Piper 端侧神经 TTS 播报（优先），可选云端 TTS 增强自然度
6. 悬浮球支持拖拽移动、三态视觉反馈（待机 / 识别中 / 播报中）

## Non-goals

- 不支持视频 / 直播内容的实时 OCR（仅静态截图识别）
- 不提供图片相册批量识别
- 不实现多语言界面（首版仅中文界面）
- 不提供账号系统或云端数据同步
- 不打包 Piper 模型文件（首次使用按需下载）
