# 2026-08-27-lasso-selection

## Why

产品决策：框选交互从"拖拽矩形"升级为"用户随手画"（套索）——用户想圈哪块画哪块，更符合"随手一划就能读"的无障碍直觉，也是原型之外的核心交互升级。现有 `SelectionView` 是 ACTION_DOWN/MOVE/UP 矩形逻辑，需重写为自由路径采集 + 包围盒识别。

## What Changes

- `SelectionView` 交互重写：MOVE 期间按采样距离（≥8dp）收集点集绘制自由笔迹（描边样式与现有紫框一致 #FF7B68EE）
- 抬手判定：路径包围盒 ≥48dp 即确认（沿用最小尺寸门槛）；识别裁剪区 = 包围盒映射到截图坐标（复用现有坐标换算）
- 视觉：屏幕蒙版遮暗，**画过的笔迹区域透亮**（路径描边反遮罩），识别中笔迹保持高亮
- 「重新框选」清空路径；新增轻提示（首次进入显示"用手指圈出要朗读的文字"）
- 被否选项：V1 即做像素级 mask 精确裁剪（OCR 需矩形输入，mask 边缘参差反引入噪声；包围盒 + 视觉套索已满足直觉），记录为后续增强
- 被否选项：多点/多圈合并（V1 单笔，抬手即识别，与现节奏一致）

## 成功标准

- 手指画任意闭合/不闭合圈，抬手即以圈的包围盒触发识别播报
- 画出的笔迹视觉高亮、遮罩外变暗；「重新框选」清空重来
- 坐标映射在竖屏全分辨率截图下准确（识别内容与圈选内容一致）
- 既有单测全绿；新增几何单测通过

## 优先级

- P2：核心交互升级，独立于引擎替换可并行。
